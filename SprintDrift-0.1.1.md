# Sprint Drift 0.1.1

Sprint Drift 0.1.1 is a trust and update-reliability release. It does not add a
new record type, account, integration, or permission.

## What changed

- Added **Report a Problem…** to the Sprint Drift app menu.
- Added **Copy Support Information**, which copies only the app version/build,
  macOS version, and Mac architecture.
- Added an in-app link to the public privacy and local-data notice.
- Added privacy-safe public issue forms plus clearer support and uninstall
  guidance.

## Compatibility

- Apple silicon only.
- macOS 15 or later.
- Existing Sprint Drift records remain local and compatible with this update.
- Optional voice capture still requires the separate 227.5 MB model download;
  transcription runs on this Mac.

## Updating

Sprint Drift checks its signed update feed automatically and asks before
installing. You can also choose **Sprint Drift → Check for Updates…**.

If you need help, choose **Sprint Drift → Report a Problem…**. Do not include
private intentions, notes, transcripts, recordings, credentials, personal file
paths, or unsanitized screenshots in a public report.
